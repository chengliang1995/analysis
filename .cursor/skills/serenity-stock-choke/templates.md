# 双模板输出骨架

本仓库两套分析模板**分开输出**；合用时先 B 再 A（或先 A 再说明「非卡脖子路径」）。

---

## 模板 A · 三维交易研判（stock-analysis-master）

用于：买卖点、持仓、超短/中线复盘。

```markdown
## 三维研判 · [代码] [名称]

### 1. 均线结构
- 结构标签：（多头/空头/纠缠）
- MA5/10/20/60 关系：…
- 操作倾向：…

### 2. 消息催化
- 催化：…（已核实 / 未核实）
- 与结构同向？：…

### 3. 情绪环境
- 大盘/板块/个股：…
- 仓位含义：…

### 结论
- 倾向：观察 / 回踩关注 / 减仓优先
- 风险：…
```

复盘用 master skill 内「选股复盘」模板。

---

## 模板 B · Serenity 卡脖子报告（本 skill）

用于：板块/产业链瓶颈选股。强制七段。

```markdown
## [板块名称] 卡脖子分析报告
strategy: serenity_choke

### 1. 板块所处周期判断
[需求爆发 / 技术跃迁 / 供给受限] + 依据

### 2. 供应链卡脖子地图
终端 → … → **[卡脖子环节]** → …

### 3. 候选标的四维信号卡
#### [简称] [代码]
- 卡脖子定位：…
- 今日走势：价格 / 涨跌幅 / 换手
- 市值与流动性：…
- 均线结构（交接）：…（来自本仓库 K 线）
- 风险：…

### 4. 筛选结论
- 真瓶颈：…
- 已排除及原因：（对应六条规则编号）

### 5. 多空信号对照
- 做多：1) … 2) … 3) …
- 风险：1) … 2) …

### 6. 今日板块资金面
（板块涨跌、领涨成份、成交通用事实；缺数据写待验证）

### 7. 操作建议
- 短线：…
- 中线：…
- 长线：…
- 风险提示：小盘波动大；不构成投资建议
```

## 合用短模板（Serenity 池 → 交易过滤）

```markdown
## 交接单 · Serenity → 三维过滤

| 代码 | 卡脖子定位 | Serenity 结论 | MA 结构 | 追高？ | 最终倾向 |
|------|------------|---------------|---------|--------|----------|
| … | … | 保留/排除 | 多/空/纠 | 是/否 | … |

说明：Serenity 负责「买什么逻辑」；三维负责「现在能不能买」。
```
