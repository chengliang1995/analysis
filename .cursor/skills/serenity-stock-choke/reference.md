# Serenity 卡脖子 · 参考手册（本仓库）

## 霍尔木兹类比

霍尔木兹是石油咽喉；A 股问题：**哪个环节是大赛道的咽喉？哪家公司卡在那里？**

```
终端需求/政策/技术跃迁
  → 上游产能跟不上
  → 瓶颈环节定价权
  → 小盘股弹性最大
```

## 周期三型

| 类型 | 特征 | 信号 |
|------|------|------|
| 需求爆发 | 终端暴增，中游扩产不及 | 涨价、订单排期拉长 |
| 技术跃迁 | 新技术替代旧技术 | 政策/标准切换、旧产能贬值 |
| 供给受限 | 原料/产能被卡 | 报价暴涨、份额即壁垒 |

## 溯源模板（每板块必过）

```
终端产品
  ↓ 最终组装/集成     ← 产能集中度？
  ↓ 核心零部件       ← 技术壁垒？
  ↓ 关键材料/元器件   ← 原料依赖？国产自给？
  ↓ 上游化工/矿产/气体 ← 资源垄断？
```

**易成卡脖子**：高壁垒、扩产 2–5 年、自给率低、寡头、不可替代、地缘管制。

## 六条排除（命中一条即剔除）

1. 有业务但非主营（蹭热点）
2. 竞争格局分散、无护城河
3. 产能扩张太容易
4. 进口替代逻辑不成立（或全球同缺且无国内卡点优势）
5. 估值/知名度已充分反映（龙头已大幅定价）
6. 流动性陷阱（日均成交额过低；本仓库默认筛掉金额过低标的）

## 四维信号卡字段

与 `serenity_choke_advisor` 候选字段对齐：

| 维度 | 字段/来源 |
|------|-----------|
| 卡脖子定位 | `choke_role`（Agent 填写）+ 板块名 |
| 估值水位 | 待验证（无统一 PE 源时标注）；可用相对涨幅/位置代替 |
| 资本/交易信号 | `pct_chg` / `turnover` / `amount` / `market_cap` |
| 结构交接 | `ma_structure` / `rsi`（供 stock-analysis-master 二次过滤） |

## 与旧模块边界

| 模块 | 职责 | 落盘 |
|------|------|------|
| `serenity_choke_advisor` | 卡脖子主题选股 | `output/serenity/` · `data/serenity_choke_picks.json` |
| `sector_recommender` | 热门板块强弱成份 | `output/sector/` |
| `midterm_*` / ultra | 中线/超短量化路径 | `midterm_pick_tracker` 等 |

评分 ID：`strategy_id = "serenity_choke"`。评估/政策模块若纳入，必须用独立 id，不得复用 `tracker_triple_breakout` 等。

## 常见板块参考（起点，非结论）

| 板块 | 常见卡脖子节点（需验证） |
|------|--------------------------|
| 光模块/CPO | EAM/激光器、MPO 连接器、光芯片 |
| 半导体设备 | 薄膜沉积、光刻核心件 |
| 军工 | 特种合金、高端复合材料 |
| 电力 | 特高压设备、调度系统 |
| 新能源车 | 导电剂、固态电池关键材料 |

## 二次过滤（兼容 stock-analysis-master）

Serenity 池 → 对入选代码跑：

- 价 vs MA20/MA60（多头优先观察；空头降权）
- 是否 MA20 上方追高 >8%
- 板块拥挤/情绪过热则降仓位表述

输出中写明：`entry_filter=stock-analysis-master`。
