# 股票分析大师 · 参考手册

## 均线细则（A 股常用）

### 周期角色

| 均线 | 角色 | 典型用法 |
|------|------|----------|
| MA5 | 超短生命线 | 站稳可持；跌破且放量→超短离场信号增强 |
| MA10 | 短线趋势 | 多头中 MA5>MA10 更健康；跌破 MA10 警惕短线转弱 |
| MA20 | 中线生命线 | 本仓库中线默认沿 MA20 持有，跌破再评估减仓 |
| MA60 | 中期趋势 | 价与 MA20 均在 MA60 上方→趋势更稳 |

### 结构标签（与 `midterm_portfolio_advisor` 对齐）

- **均线多头**：价 ≥ MA20 ≥ MA60
- **均线空头**：价 ＜ MA20 ≤ MA60
- **均线纠缠**：其余（震荡/转换期）
- **RSI 参考**：45–65 健康；≥75 超买；≤35 超卖（需结合支撑）

### 买卖时机启发式

- 买入价 / MA20 ＞ 1.08 → **偏高追高**（实盘复盘扣分项）
- 买入价 / MA20 ＜ 0.95 → 相对低位（仍需看趋势未坏）
- 盈利卖出价显著低于持仓期高点（如＜90%）→ 可能卖早；可讨论分批止盈
- 超短策略持仓 ＞3 日 → 周期错配风险
- 中线单笔亏损 ≤ -8% → 检查止损是否执行

### 量价配合

- 回踩均线 + 缩量：健康
- 破均线 + 放量：危险
- 无量阴跌 vs 放量杀跌：后者更需果断

## 消息面评估清单

1. **来源**：官方公告 / 权威媒体 / 传闻（传闻默认低权重）
2. **新旧**：是否已在近几日涨幅中反映
3. **力度**：主题级 / 公司级 / 一日情绪级
4. **证伪路径**：何种数据或公告会推翻逻辑
5. **与结构同向？** 同向加强；逆向以降风险为先

## 情绪分层快检

| 层级 | 观察点 | 过热信号 | 冰点信号 |
|------|--------|----------|----------|
| 大盘 | 指数位置、涨跌家数、成交额 | 普涨高位放量 | 普跌缩量或恐慌砸盘后 |
| 板块 | 连板高度、回流/分歧 | 高位接力拥挤 | 龙头断板、题材退潮 |
| 个股 | 换手、封单、开板次数 | 高换手滞涨 | 地量或恐慌长阴后企稳 |

情绪只调整仓位与买点要求，不单独构成开仓理由。

## 归因词表（复盘用语保持一致）

**成功侧常见主因**

- 买点贴近 MA20/MA5 回踩，未追高
- 催化兑现且结构同向
- 情绪共振但未接到最后一棒；止盈纪律到位
- 因子可复制（如「缩量回踩 MA20 + 板块未退潮」）

**失败侧常见主因**

- MA20 上方追高，买点偏高
- 结构已空头仍按多头逻辑持有
- 催化证伪或纯情绪脉冲结束
- 超短单拖成中线 / 中线单用超短止损错配
- 破位未执行止损，亏损扩大

**中性/样本问题**

- 跟踪未到期（interim）
- 样本不足（成熟样本过少）
- 行情源缺失导致无法评估结构

## 批次复盘汇总表示例

| 代码 | 名称 | 收益% | 结果 | 主因标签 | 下次动作 |
|------|------|-------|------|----------|----------|
| 600xxx | … | +5.2 | 成功 | 回踩MA20+催化兑现 | 保留该买点模式 |
| 000xxx | … | -4.1 | 失败 | 追高+情绪退潮 | 过滤 MA20 上方>8% |

主因标签尽量短（≤12 字），便于统计分布。

## 与仓库模块的数据字段提示

### `midterm_pick_tracker`

- 关注 `summary.win_rate`、`avg_return`、`factor_insights`
- interim 摘要在样本未成熟时可用，但输出须标注「阶段性」
- 胜负阈值默认约 +3% / 约 10 交易日（以当前模块常量为准）

### `real_portfolio_reviewer`

- 字段：`buy_timing`（偏高/低位/合理）、`sell_timing`、`issues`、`timing_score`
- 建议列表常含：追高过多、卖早、超短持仓过长

### 调优反馈

归因结论若要落到参数，应对齐 `selection_tuning` / `ai_learning_optimizer` 的既有因子与边界；**仅用户明确要求时**再改代码或写回配置。

## 单笔归因完整示例

```markdown
## 选股复盘 · 600001 示例股 · 2026-03-01～03-15

**结果**：失败 · 收益 -4.8% · 持仓 8 日
**原假设**：均线多头 + 行业政策催化，中线回踩 MA20 买入

### 成功/失败主因
1. 实际买在 MA20 上方约 9%，属追高，容错不足
2. 政策利好当日高开消化，持有期无新催化
3. 板块从分歧转为退潮，个股放量跌破 MA20 后未及时减仓

### 三维回顾
- 均线：买入时价>MA20>MA60；第 5 日放量跌破 MA20，结构转弱
- 消息：政策属主题级，但买入时已部分 price-in；无业绩验证
- 情绪：板块连板高度回落，接力意愿下降

### 可复制 / 应排除
- 下次保留：政策催化需等缩量回踩 MA20 再评估
- 下次过滤：MA20 上方涨幅>8% 且板块已退潮时不新开中线仓
```
